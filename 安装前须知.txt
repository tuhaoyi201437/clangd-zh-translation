================================================================
 clangd 中文报错 · 纯翻译层   安装前须知（必读）
================================================================

本包不含 clangd 本体，也不含 Python 运行时。安装脚本要在
「你的 clangd 安装目录」旁边找到 clangd.exe，所以解压位置有硬要求。

----------------------------------------------------------------
【一、必须这样放：整个文件夹放进 clangd 目录里】

  把 zip 解压出的整个文件夹，放进你的 clangd 目录，与 bin、lib 同级。
  装好后应当是这个结构：

     C:\clangd\                     <- 你的 clangd 目录
       |-- bin\clangd.exe           <- clangd 本体（原本就有）
       |-- lib\                     <- 原本就有
       |-- clangd-zh.cmd            <- 本机原有文件，不动它
       `-- clangd-zh-portable\      <- 本包解压到这里
             |-- 安装前须知.txt
             |-- 安装.cmd
             |-- install.py
             |-- clangd-zh.cmd
             |-- clangd_zh_proxy.py
             |-- zh_codes.py
             |-- zh_diagnostics.py
             `-- compile_flags.txt

  * 文件夹名可以改，但必须直接放在 clangd 目录下，不能再套一层。
  * 整个文件夹一起移动，不要只拷单个文件。
  * clangd 目录本身在哪个盘、路径有没有中文或空格，都不影响。

----------------------------------------------------------------
【二、安装时只查当前目录，不扫全盘】

  install.py 找 clangd.exe 只认下面 4 个位置，按顺序取第一个存在的：

     1  <本包目录>\clangd.exe
     2  <本包目录>\bin\clangd.exe
     3  <本包目录>\..\clangd.exe          （即 clangd 目录下）
     4  <本包目录>\..\bin\clangd.exe      （即 clangd\bin，推荐布局命中这条）

  不会查 PATH，不会查 Program Files\LLVM，也不会扫 C:/D:/E: 等其他盘。
  这样做的原因很实际：机器上同时装过多份 clangd 时，绝不会悄悄用错
  那一份，出问题也容易定位——用的就是你放进来的这份。

  如果 4 处都没有，安装会立刻停下，并把上面 4 条路径原样打印出来，
  方便你对照自己实际放在了哪里。此时两条路：

     a) 把文件夹挪到正确位置（推荐，按【一】的结构放）；
     b) 临时指定：
          set "CLANGD_EXE=C:\clangd\bin\clangd.exe"
          安装.cmd
        环境变量属于人工指定，优先级最高，会直接跳过目录探测。

----------------------------------------------------------------
【三、另外两样依赖仍然是自动探测的】

  Python 3.8+   查 py -3、PATH、%LOCALAPPDATA%\Programs\Python、C:\Python3*
                找不到就用 CLANGD_PY 手动指定。

  g++ / MinGW   查 PATH 与常见安装位置，只用来读标准库头文件路径。
                找不到也能装完，只是 #include <bits/stdc++.h> 会报
                "file not found"；补装后重跑安装即可。可用 CLANGD_GXX 指定。

  这两个变量的用法见同目录「使用说明.txt」第三节。

----------------------------------------------------------------
【四、放好之后怎么办】

  双击「安装.cmd」。看到「验证通过」和「中文诊断端到端 : OK」之后，
  到 VS Code 里按 Ctrl+Shift+P -> Reload Window（不能省，已运行的
  代理进程不会热更新），之后打开 .cpp 文件，报错就是中文了。

  完整步骤、开关用法（tasks.json 里 clang-zh 设 null 即关闭翻译）、
  常见问题，都在同目录「使用说明.txt」里。
